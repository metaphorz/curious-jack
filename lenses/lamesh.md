# LA MESH

## Abstract

This is an app that explores different lenses when examining an image. A lens is defined as a knowledge category that we find in school or at the library (e.g. Dewey Decimal, Library of Congress). The image shows first and then allows the user to point and lick on an area in the image. Since the image is segmented (e.g. segmentation mask obtained by Nano Banana Pro), each image has N segments with an additional whole-image icon in the upper right. Each tab for an object specifies lens-specific information. At the top of the box which pops-up when the mouse is clicked. A box window appears. Each box has M tabs. In a tab, there is a title, and often this is hyperlinked to find more generation information on that topic. And then below that title, there is an image or diagram of that topic. Below that will be optional text. 

The builder of this app organizes the layout of the app with the help of an AI coder such as Claude Code or Claude Desktop. We call the builder the curator and the end user the visitor.

The age-range of described material, if not otherwise specified, is 9th or 10th grade.

## Lenses

While tabs are lenses, and each lens is a school or academic topic, it is also possible to use a more guided approach we call LA MESH. This is an acronym: L for Language, A for Art, M for mathematics, E for engineering, S for Science and H for History.
